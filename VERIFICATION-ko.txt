옥자막 2.0.0 / build 31 확인 범위
2026-10-18

환경: Intel Mac, macOS 15.7.4. Apple Silicon 실기기 실행 검사는 하지 않았습니다.

문장 흐름
- 사용자 시험을 거친 문장 흐름 시험2의 분석·분할 코드를 정식판에 그대로 포함했습니다.
- 원문/순서 보존, 경계 시간, 긴 문장·후치 명사구·관형어·보조동사·인용문과 숫자 표기 회귀 검사.
- 실제 음성 샘플과 동일한 받아쓰기 결과를 이용한 이전/개선 분할 비교.
- 임의의 구어체, 정확한 화자 전환과 단어별 시간 정렬의 완벽함을 보장하지 않습니다.

스타일/반응형 박스
- 스타일 임시 변경과 실제 적용 구별, 재실행·새 프로젝트, 선택 자막만 적용, 실행 취소, 저장 스타일 이름 변경/삭제, 기존 프로젝트 우선, 손상 파일/저장 실패 처리 검사.
- HD/UHD/세로 프로젝트에서 상하 여백 0/3/40/120 값을 내보내고 Motion의 Y Offset 연결과 비교.
- v2 타이틀 최초·반복 설치, 사용자 수정본 보존, 이전 v1 분리 검사.
- 이번 자동 검사는 내보낸 XML과 템플릿 연결을 확인한 것으로, 파컷의 모든 글꼴·해상도·렌더 결과를 검사한 것은 아닙니다.

업데이트
- 별도의 격리된 시험 앱으로 Sparkle 서명 검증 후 다운로드·실제 파일 교체 검사.
- 변조된 업데이트 정보/압축파일 거부, 다운로드 취소, 새 버전 없음 처리 검사.
- 파컷·확장·받아쓰기/번역 진행 상태의 설치 차단 조합 검사.
- 정식 배포용 피드와 업데이트 ZIP은 동일한 서명 키를 사용합니다.
- 1.x에는 이 기능이 없으므로 이번 2.0 설치는 수동 교체가 필요합니다.

패키지
- 앱·파컷 확장·타이틀 설치 도우미·제거 도구의 2.0.0/build31 및 공용 아키텍처 확인.
- Intel 전용 AVX2 엔진은 지원되는 Intel CPU에서만 선택하며 범용 엔진을 별도로 유지합니다.
- 기본 Base 모델·말소리 모델·다운로드 목록·라이선스와 기존 모델 저장 경로 확인.
- 시험판에서 폐기한 이름/애칭 검토 LLM은 포함하지 않습니다.
- 로컬 코드 서명 구조 검사. Apple Developer ID 서명·공증을 받았다는 뜻은 아닙니다.

설치 안내의 지원 범위와 제한을 함께 확인해 주세요.
